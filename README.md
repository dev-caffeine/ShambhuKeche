## Statistical Methods Applied

- Descriptive statistics (mean, median, SD, skewness, kurtosis, IQR, CV)
- Grouped frequency tables & ogive
- Outlier analysis (1.5 × IQR rule)
- Statistical moments (raw & central)
- Probability: conditional probability, Bayes' theorem
- Theoretical distributions: Binomial, Poisson, Normal / Z
- Jarque–Bera normality test
- Pearson correlation matrix
- Simple & Multiple Linear Regression (OLS)
- Hypothesis testing: one-sample t-test, Welch's two-sample t-test, regression slope t-test
